# 第八章 营改增与现今财税体制（2012—至今）：央地收入格局的系统研究

营改增是 1994 年以来最大的单项税制改革：它打通了货物与服务的增值税抵扣链条，也拿走了地方唯一的主体税种。本章以全国与分省数据系统考察改革前后的央地收入格局：增值税五五分成如何对冲地方损失、各省财政自给率的分化梯度、转移支付依赖的省际图景，以及土地出让金退潮后地方财政的现实处境。

> 数据口径说明：如无特别注明，均为一般公共预算口径，取自财政部历年全国财政决算、《中国财政年鉴》、各省决算报告；标注"约"者为据公开决算整理的近似数。土地出让收入属政府性基金预算，单独注明。

## 一、改革历程与逻辑

| 时间 | 节点 |
| --- | --- |
| 2009 | 增值税由生产型转消费型（固定资产进项可抵扣） |
| 2012.1 | 上海试点：交通运输业+部分现代服务业营改增 |
| 2012.8—2013 | 试点扩至北京等省市，继而全国推开试点行业 |
| 2014 | 铁路运输、邮政、电信业纳入 |
| **2016.5.1** | **全面营改增**：建筑、房地产、金融、生活服务四大行业纳入，营业税退出 |
| 2016.5 | 国务院《全面推开营改增试点后调整中央与地方增值税收入划分过渡方案》：**增值税央地五五分成** |
| 2017—2018 | 营业税暂行条例废止；增值税税率简并（四档→三档：16/10/6，2019 再降为 13/9/6） |
| 2018 | **国税地税机构合并**；社保费交由税务征收（2019—2020 过渡） |
| 2019 | 个人所得税综合与分类相结合改革（专项附加扣除）；五五分成维持并建立留抵退税分担机制 |
| 2022 | 大规模增值税留抵退税（全年约 2.46 万亿元） |

**改革逻辑**：营业税按营业额全额征收、不得抵扣，服务业存在重复征税，且货物（增值税）与服务（营业税）两税并行割裂抵扣链条，妨碍制造业服务化与专业化分工。营改增统一为增值税后，抵扣链条贯通，叠加税率下调与留抵退税，2016—2022 年新增减税降费及退税缓费累计超 13 万亿元——**营改增同时是一场延续多年的大规模减税**。

## 二、改革前后的全国央地收入格局

### （一）改革前：营业税作为地方主体税种

- 2015 年（全面营改增前最后一个完整年度）：全国营业税收入 **1.93 万亿元**，其中约 98% 归地方，约占**地方本级税收收入的三分之一**，是地方第一大税种；增值税 3.11 万亿元，央地 75:25 分成。
- 地方由此拥有一个税基广（全部服务业+建筑+房地产）、与地方经济活动直接挂钩、征管在地税系统手中的主体税种——**这是 1994 体制留给地方的最大一块"自留地"**。

### （二）改革后：五五分成与地方主体税种的消失

- 2016 年过渡方案将增值税分成从 75:25 调整为 **50:50**，以 2014 年为基数核定中央返还与地方上缴，保障各地既有财力不减；中央集中的增量主要经均衡性转移支付倾斜中西部。
- 结构性后果：地方税收中**共享税占比大幅上升、专属税种萎缩**——2023 年地方本级税收中，共享的增值税与企业/个人所得税地方分成部分合计约占六成；地方专属主体税种阙如，房产税+城镇土地使用税+土地增值税+契税等财产行为税合计仅占地方税收约四分之一，且其中土地增值税、契税高度依赖地产周期。

### （三）央地收入占比的时间序列（一般公共预算，约数）

| 年份 | 全国收入（万亿元） | 中央本级占比 | 地方本级占比 | 备注 |
| --- | --- | --- | --- | --- |
| 1993 | 0.43 | 22.0% | 78.0% | 分税制前夜 |
| 1994 | 0.52 | 55.7% | 44.3% | 分税制元年 |
| 2000 | 1.34 | 52.2% | 47.8% | |
| 2010 | 8.31 | 51.1% | 48.9% | |
| 2012 | 11.73 | 47.9% | 52.1% | 营改增试点启动 |
| 2015 | 15.22 | 45.5% | 54.5% | 全面营改增前 |
| 2017 | 17.26 | 47.1% | 52.9% | 五五分成后首个完整年度 |

**解读**：收入占比上中央稳定在 45—48%，营改增+五五分成大体实现了"央地财力格局总体不变"的承诺；但**支出端地方占比高达 85% 以上**（2023 年地方一般公共预算支出 23.6 万亿 vs 中央本级 3.8 万亿）——**收入近半在中央、支出八成五在地方**，缺口由转移支付回填：2023 年中央对地方转移支付约 **10.3 万亿元**，相当于地方本级收入的 88%。这一"集中—返还"的资金大循环是现行体制的核心特征。

## 三、分省格局：自给率梯度与转移支付依赖

### （一）财政自给率的省际分化（2023 年，一般公共预算本级收入/支出，约数）

| 梯队 | 省份（自给率约数） | 特征 |
| --- | --- | --- |
| 第一梯队（>70%） | 上海（~93%）、北京（~82%）、浙江（~78%）、广东（~74%）、江苏（~72%） | 税基厚（总部经济、金融、数字经济、制造业），为净上缴省份 |
| 第二梯队（50—70%） | 天津（~60%）、山东（~58%）、福建（~56%）、安徽（~45—50%） | 基本自立，略受转移支付补充 |
| 第三梯队（30—50%） | 四川（~40%）、河南（~38%）、湖南/湖北（~35—45%）、重庆（~45%）、陕西（~45%）、辽宁（~45%）、江西/广西/云南（~30—35%） | 支出半数以上靠中央 |
| 第四梯队（<30%） | 贵州（~28%）、吉林（~27%）、新疆（~25%）、甘肃（~22%）、黑龙江（~21%）、青海（~15%）、西藏（~11%） | 深度依赖转移支付 |

**结构性观察**：
1. 净贡献省份长期只有**七八个**（粤苏浙沪京津闽及部分年份山东），它们的净上缴支撑着其余省份与中央本级支出——与前篇"唐后期东南八道上供养天下"、清代"协饷"的空间结构一脉相承：**财赋东南的千年格局在数据上依旧清晰**。
2. 转移支付绝对额最大的省份为人口与农业大省：2023 年四川（约 6100 亿）、河南（约 5300 亿）、湖南、湖北、河北、黑龙江等均在 3500—6000 亿元级——人均口径则西藏、青海、宁夏居前（西藏人均转移支付超 6 万元，为人均自有收入的数倍）。
3. 县级"三保"（保基本民生、保工资、保运转）压力集中在第三四梯队——2023 年起中央反复强调"三保"底线与省级兜底责任。

### （二）营改增对不同省份的差异化冲击

- **服务业占比越高的省市，原营业税依赖越深**：2015 年北京、上海营业税占地方税收比重超 35%（金融、信息、商务服务业密集），全面营改增的名义冲击最大，但两地同时是增值税五五分成与总部经济的最大受益者，实际财力未受损。
- **建筑与房地产大省**：营业税中建筑业与房地产业合计约占一半，改革后两行业增值税（9% 档）与地产相关税费继续与楼市绑定——2021 年后地产下行对这类省份（及县市）形成**"增值税分成+土地出让金+土地增值税契税"三重同向收缩**。
- **制造业省份**相对受益：抵扣链条打通降低制造业税负，粤苏浙的制造业增值税税基扩张部分对冲了营业税消失；而 2022 年大规模**留抵退税由央地共同负担（中央承担约 50% 并对中西部提高补助）**，制造业大省当年地方收入出现罕见负增长（全国地方本级税收 2022 年下降约 10%，扣除退税因素后为正）——显示共享税体制下**中央减税政策的成本自动传导至地方**。

### （三）土地出让金退潮与地方综合财力（政府性基金口径）

| 年份 | 全国土地出让收入（万亿元） | 相当于地方一般公共预算本级收入 |
| --- | --- | --- |
| 2017 | 5.2 | 57% |
| 2019 | 7.3 | 72% |
| **2021** | **8.7（峰值）** | **78%** |
| 2022 | 6.7 | 61% |
| 2023 | 5.8 | 49% |
| 2024 | 4.9 | 约 41% |

- 2021—2024 年土地出让收入缩水约 44%，**对市县综合财力的冲击超过营改增本身**；依赖度最高的并非一线城市（土地溢价高但财政盘子更大），而是此前高杠杆扩张的二三线与县域（如部分中西部省会新区、环一线城市圈）。
- 连锁反应：地方政府法定债务余额 2024 年末约 47 万亿元（一般债+专项债），城投平台有息债务学界估算另有 50—60 万亿元级；2023 年"一揽子化债"（特殊再融资债券置换）与 **2024.11 的 10 万亿元化债方案**（6 万亿置换额度+连续数年专项债额度安排），标志隐性债务进入集中清理期——**土地财政时代的资产负债表正在被动收缩与重组**。

## 四、现行体制的评估与改革方向

### （一）评估

1. **"强干"目标已稳固实现**：中央通过共享税+垂直征管（国地税合并后更甚）牢牢掌握税基，任何地方无从截留——历代"税基流失于地方"的命题已被技术性终结。
2. **"弱枝"问题换了形态**：地方不再有割据性财权，但也失去自立性财源——主体税种缺位+土地财政退潮+隐性债务约束，使地方（尤其县级）高度依赖转移支付与上级政策，**积极性与财政可持续性成为新的系统性短板**；"收入集中—支出下压—转移回填"的大循环行政成本高、激励扭曲多（基数博弈、项目包装）。
3. **历史坐标**：现行格局接近"宋制"的现代版——财赋尽归中央再统一调配，换取政治安全与区域均衡，代价是地方机动能力弱化。与宋不同的是规模：10 万亿级的年度转移支付与 47 万亿级的地方债务，使央地财政关系的任何调整都牵动宏观稳定。

### （二）改革方向（以二十届三中全会〔2024.7〕部署为准）

1. **增加地方自主财力**：推进**消费税征收环节后移并稳步下划地方**（现为中央税，约 1.6 万亿元规模，后移至批发零售环节可同时扩大税基并激励地方改善消费环境）；研究将城市维护建设税、教育费附加、地方教育附加**合并为地方附加税**并授权地方在幅度内确定税率；规范非税收入管理。
2. **央地事权再划分**：适当加强中央事权（提高中央本级支出比例，减少委托地方代行）、完善共同财政事权保障标准——矫正"支出 85% 在地方"的失衡。
3. **房地产税**：作为地方财产税主体税种的长期选项，2021 年人大授权试点后因地产下行**暂缓**——短期内难以接棒土地出让金。
4. **债务制度化**：专项债扩容提效、隐性债务显性化、建立与高质量发展相适应的政府债务管理机制——把"影子财政"收编入预算国家框架。
5. **全国统一大市场**：清理地方税收优惠与"税收洼地"招商（2024 年起整治"内卷式"招商返税）——包干时代遗留的地方让利竞争进入清理期。

## 五、小结

1. 营改增完成了 1994 年未竟的税制统一（流转税一元化），其央地后果以"五五分成+转移支付扩容"平滑，收入占比层面波澜不惊；**真正的结构性变化在于地方从此没有了自己的主体税种，财政自主性降至 1949 年以来（和平时期）最低点**。
2. 分省数据显示的三重梯度——自给率的东西梯度、转移支付依赖的南北差异、土地财政退潮的冲击分布——构成理解当下中国区域经济与地方行为的财政底图。
3. "营业税之后，地方主体税种何在"仍无最终答案：消费税下划、地方附加税是中期方案，房地产税是长期悬念——**央地财政关系的"钟摆"并未停止，只是摆动从"崩溃—重建"进化为预算国家框架内的参数调整**。这正是两千年央地财政命题的现代形态。
