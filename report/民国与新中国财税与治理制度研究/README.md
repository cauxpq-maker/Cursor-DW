# 民国与新中国：现代中国财税与治理制度研究（1912—至今）

## 研究主旨

本报告是《汉至清：中国历代财税与治理制度变迁研究》的续篇，将"财政税收制度决定国家强盛与兴衰"的分析框架延伸至现代：考察中华民国的财政危机与其覆亡的因果关系，梳理中华人民共和国建立以来历次财政危机与财税、土地制度改革，并以分省数据系统研究营改增前后中央与地方的收入格局。

三个研究重点：

1. **中华民国财政危机与政权覆亡的关系**——军费失控、恶性通胀与汲取失败的死亡螺旋；
2. **新中国历次财政危机与财税土地制度改革**——统收统支、财政包干、分税制的转轨逻辑；
3. **营改增前后央地收入格局**——以全国与分省数据呈现地方主体税种消失后的财政图景。

## 阅读说明

- 每章延续前报告"土地—税收—财政—军费—干部选任—央地关系"框架，并按现代情境增加货币银行、外债主权、政党组织三个变量。
- 财政数据取自财政部历年决算、《中国财政年鉴》《中国统计年鉴》及学界通行估算，均标注年份；分省数据以一般公共预算口径为主，标注"约数"者为依据公开决算的整理估算。
- 本报告为学术性制度史研究，对各时期制度得失的分析均以财政绩效为尺度。
