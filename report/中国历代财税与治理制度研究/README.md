# 汉至清：中国历代财税与治理制度变迁研究

## 研究主旨

中国的朝代更迭既是统治者的变更，也是经济周期变化的结果。"开阡陌、废井田"是生产关系的变化，也是政治制度、治理结构与财税制度的变化。财政税收制度在相当程度上决定一个国家的强盛与兴衰。本研究以汉代至清代的主要朝代为对象，从以下六个维度系统考察制度变迁及其联动关系：

1. **土地制度**——生产关系与税基的根基
2. **税收制度**——国家汲取资源的方式与对象
3. **财政制度**——收支管理、专卖、货币与库藏体系
4. **兵制**——国家暴力机器的供养方式，历代财政的最大支出项
5. **官员选拔制度**——官僚机器的人才来源与激励结构
6. **中央与地方的权力分配**——财权、兵权、人事权在央地之间的配置
