# 第一章 汉朝（前 202—220）：编户齐民与轻徭薄赋的帝国原型

汉承秦制而去其苛暴，建立了此后两千年帝制财政的"原型"：以编户齐民为基础、田租与人头税并行、中央专卖补充、征兵制军队、察举选官、郡县（郡国）治理。汉朝也第一次完整演示了王朝周期律——轻徭薄赋开国、豪强兼并坐大、税基流失、财政崩溃而亡。

## 一、土地制度：名田制下的小农经济与豪强兼并

- **名田制**：土地私有、以户籍登记（"名田"即以名占田），可自由买卖。汉初经战乱人口锐减，政府授田安置流民复员军士，形成大量五口之家、耕田约百亩的自耕农——他们是国家的税基与兵源。
- **兼并的螺旋**：土地可买卖+人头税固定，意味着灾年小农破产卖地后税负不减，只能沦为豪强佃客或流民。文帝时晁错《论贵粟疏》已警告"卖田宅、鬻子孙以偿债者"；武帝以后"富者田连阡陌，贫者无立锥之地"（董仲舒语）。
- **限田的失败**：董仲舒建议"限民名田"未行；哀帝时师丹限田限奴婢方案遭权贵抵制流产；王莽托古改制行"**王田制**"（土地国有、禁止买卖，实为井田复辟），三年即被迫废止，新朝旋亡。**限制兼并的首次系统尝试均告失败，证明在土地私有+人头税框架内此问题无解。**
- **东汉豪强庄园**：光武帝依豪强起家，"度田"（清丈土地）遇抵制后不了了之。豪强田庄自给自足、荫庇宾客部曲，大量人口脱离国家户籍——东汉的税基从根上被掏空。

## 二、税收制度：轻田租、重人头的结构性偏差

| 税目 | 内容 | 说明 |
| --- | --- | --- |
| 田租 | 汉初十五税一，文帝减至三十税一并一度全免，东汉沿袭三十税一 | 税率极低，但按土地征收，利在有地者 |
| 算赋 | 15—56 岁成人每人每年 120 钱 | 人头税主体，货币缴纳 |
| 口赋 | 3（一说 7）—14 岁儿童每人 20 钱（武帝加至 23 钱） | 迫使贫民"生子辄杀"的记载屡见 |
| 更赋 | 代役钱：不服徭役者每年纳钱（过更约 300 钱/月役） | 徭役货币化的开端 |
| 徭役兵役 | 每丁每年劳役一月，一生戍边一年、正卒一年 | 实物财政之外的劳役汲取 |

**结构性偏差**：田租轻而人头税重、且人头税须以货币缴纳，等于累退税——豪强地主受惠，小农为换钱纳赋被迫贱卖粮食，"卖青苗"借高利贷，加速破产兼并。这一偏差是汉代（也是历代前期税制）最深刻的教训，此后税制演进的总方向就是**从税人转向税地**（至清摊丁入亩才最终完成）。

- **武帝的非常财政**：对匈奴战争耗尽文景积蓄，武帝遂行**算缗**（对商人财产征 6% 财产税）、**告缗**（鼓励告发瞒产、没收其半），"商贾中家以上大率破"；又卖官鬻爵、铸皮币白金。此为中国史上最激烈的一次对商业财富的国家掠夺，短期充盈国库，长期摧抑民间商业。

## 三、财政制度：大司农与少府的两套库藏、盐铁专卖与五铢钱

- **国家财政与帝室财政分立**：**大司农**掌田租、算赋等国家正税，供军国之用；**少府**掌山海池泽之税、口赋、献费，为皇帝私奉养。这一"公私两藏"格局为后世（唐内库、明内帑、清内务府）所继承，皇室财政挤占国家财政亦成为历代痼疾。
- **盐铁专卖（前 119 年）**：武帝用桑弘羊，收盐、铁、酒专卖于官，"笼天下盐铁"以济军费。昭帝时盐铁会议（前 81 年，《盐铁论》）贤良文学激烈抨击，但专卖制度被保留——**自此国家专卖成为与农业税并立的财政支柱，历代相沿**。
- **均输、平准（前 110 年）**：均输官统一征收、运输、出售各郡贡物，平准官在京师贱买贵卖平抑物价——国家直接经营商业物流，开后世常平仓、市易法先河。
- **货币**：武帝收铸币权于中央，行**五铢钱**（前 113 年），质量稳定沿用七百余年，是中央集权财政的货币基础。西汉末与新莽滥改币制（王莽宝货制六名二十八品）造成经济大乱，为滥发货币祸国的最早完整案例。

## 四、兵制：从全民征兵到募兵、部曲

- **西汉征兵制**：编户男子 23（后 20）岁傅籍，服正卒（郡国材官骑士训练一年）、戍卒（京师或边郡一年），之后为预备役。京师有南军（卫宫）北军（卫城）。**兵源与税源同一，皆系于编户齐民**。
- **武帝以后的职业化**：长期对外战争使一年期征兵不敷使用，出现募兵（期门、羽林、佽飞）、刑徒兵、属国胡骑；边郡行**屯田**（军垦自给），赵充国屯田湟中为典范——屯田是此后历代解决边防军粮的标准方案。
- **东汉罢郡国兵**：光武帝罢材官骑士（31 年），地方常备军裁撤，中央靠募兵与刑徒，边防靠胡人雇佣——财政上省钱，军事上使国家丧失动员体系。黄巾起义时朝廷无兵可用，被迫令州郡自募，**兵权下移，豪强部曲（私兵）合法化，直接导向军阀割据与三国分裂**。

## 五、官员选拔：察举征辟与门阀的萌芽

- **察举制**：由郡国守相定期举"孝廉"（武帝元光元年定制，每郡岁举）、不定期举"贤良方正""茂才"等，经考核任官；辅以**征辟**（公府州郡自行辟除掾属）、**任子**（二千石官任职满三年可保举子弟）、**赀选**（家资达标者可为郎）。
- **太学**：武帝立太学置五经博士弟子，经考试补官，是科举制的远源。东汉太学生至三万人。
- **异化**：察举权在地方长官，东汉后期为豪强名士垄断，"举秀才，不知书；察孝廉，父别居"；门生故吏遍天下的世家（如弘农杨氏、汝南袁氏四世三公）形成——**察举制的门阀化是九品中正制的前奏，选官权与地方社会权力结合，侵蚀皇权**。

## 六、央地关系：从郡国并行到州牧割据

- **郡国并行与削藩**：汉初分封同姓王，王国自置官吏、自征赋税、自铸钱（吴王濞即山铸钱、煮海为盐而富甲天下）——财政独立是七国之乱（前 154 年）的底气。平乱后景帝收王国行政权，武帝行**推恩令**（前 127 年）析分王国、**左官律**《**附益法**》孤立诸侯、**酎金夺爵**（前 112 年一次削侯百余），王国问题终结。
- **刺史制度（前 106 年）**：全国分十三部州，刺史以六百石小官巡察二千石郡守，"以卑临尊"，是低成本监察地方的制度创新。
- **州牧之祸**：东汉末黄巾乱起，改刺史为**州牧**（188 年），授以一州军政财全权——监察区变行政区、监察官变割据诸侯（袁绍、刘表、刘焉皆以州牧起家）。**这是中国史上"监察官实职化—地方坐大"循环的第一次完整上演**（唐之节度使、清末之督抚将重演此剧）。

## 七、小结：汉朝的制度因果链

1. **开国**：轻徭薄赋+编户齐民 → 文景之治，国库"贯朽粟陈"。
2. **转折**：武帝大战匈奴 → 非常财政（专卖、算缗、卖爵）→ 民力耗竭，"海内虚耗，户口减半"。
3. **衰亡**：人头税累退+土地兼并 → 小农破产、豪强隐匿人口 → 税基兵源双重流失 → 中央裁军省钱 → 乱起无兵 → 兵权财权下移州牧豪强 → 帝国解体。

汉朝确立的"田租—人头税双轨+专卖补充"税制、"公私两藏"财政、察举选官、监察区治理，构成此后历代制度演化的基准线；而它暴露的"税人重于税地必致兼并亡国"的机制，则规定了此后两千年税制改革的总方向。
