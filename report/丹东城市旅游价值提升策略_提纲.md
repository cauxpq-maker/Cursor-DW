## 一、背景与趋势判断:丹东正站在一个真实的风口上

### 1.1 现阶段中国旅游消费的结构性变化
- 从"观光打卡"到"体验沉浸":游客为内容、情绪价值和仪式感付费,而非单纯为景观付费
- 公路旅行/自驾游成为增长最快的出行方式之一,"此生必驾"类线路 IP(318、G219、G331)持续升温
- 县域游、边境游、反向旅游兴起,资源"非顶流"城市获得历史性机会窗口
- 银发旅居、候鸟式度假规模化,低生活成本 + 好气候 + 医疗可及的城市受益
- 性价比时代:游客对门票价格敏感,对"一票多日""城市通票"接受度高

### 1.2 政策与基础设施窗口期
- 2026 年 7 月国新办发布会:"十五五"全面贯通 G219、G331、G228,构建中国"黄金大外环"
- G331(沿边,丹东—阿勒泰,9333 公里)与 G228(沿海,丹东—东兴,约 7800 公里)双起点均在丹东——全国唯一
- G331 丹东段获评"自驾游精品线路";零公里地标改造完成,国门湾房车营地日接待近 300 辆房车,已现自发流量
- 沿边开放、兴边富民政策叠加,边境城市文旅获得专项支持通道

### 1.3 对标研究(方法论提炼,不照搬形态)
- 河南文旅样本:万岁山武侠城(低价高频票务 + NPC 玩家化运营 + 高频内容更新)、只有河南·戏剧幻城(在地文化的沉浸式精品表达)、洛邑古城(汉服产业链)、清明上河园(双 IP 长线运营);共性 = 产品为王、沉浸互动、极致性价比、真诚服务
- 资源禀赋无绝对优势城市的出圈路径:淄博(服务与真诚)、天水(美食单品引爆)、延吉(边境 + 民族风情,与丹东最可比)、榕江村超(全民参与事件)、泉州蟳埔(民俗视觉符号)
- 提炼可迁移规律:一个尖锐的记忆点 → 政府兜底服务口碑 → 产品快速跟上承接流量 → 从流量到留量

## 二、丹东旅游资源盘点与价值重估

### 2.1 "起点之城"资产(核心差异化,全国唯一性)
- G331 零公里、G228 起点、虎山长城(明长城最东端起点)、獐岛(万里海疆最北端起点)——"四个起点"叙事
### 2.2 边境江海资产
- 鸭绿江、断桥、一步跨、跨境视野(对望新义州)、口岸与国门景观
### 2.3 红色资产
- "英雄城市":抗美援朝纪念馆、断桥、河口毛岸英学校、抗美援朝出征地叙事
### 2.4 山水生态资产
- 凤凰山、天桥沟(枫叶)、青山沟、绿江村("塞外小江南")、大鹿岛/獐岛海岛
### 2.5 温泉康养资产
- 五龙背、东汤温泉,东北少有的"江—海—泉"组合
### 2.6 物产与美食资产
- 黄蚬子、东港海鲜、99 草莓、板栗、朝鲜族冷面/打糕,单品引爆潜力评估
### 2.7 城市人文资产
- 银杏之城(百年银杏街)、安东老城记忆、轻纺工业遗产、朝鲜族风情街区
### 2.8 短板与错位诊断
- 淡旺季极端分化、景点散而不联、夜间产品缺失、沿江体验断点、住宿结构老化、"过路化"(自驾客打卡即走)

## 三、城市 IP 体系打造

### 3.1 主 IP 定位
- 「中国边境,从丹东开始」/「此生必驾,始于丹东」——"双起点之城"作为统领性心智
### 3.2 副 IP 矩阵(分客群、分季节)
- 英雄之城(红色研学)、银杏之城(秋季流量)、江海温泉之城(康养旅居)、边境风情之城(猎奇体验)
### 3.3 仪式感与符号系统
- 零公里发车仪式、"环游中国第一枚章"通关护照、起点纪念车贴/邮戳/证书,把地理概念做成可带走的仪式产品
### 3.4 传播策略
- 话题工程(#从丹东出发环游中国#)、自驾/摩旅/骑行社群深度运营、事件营销日历(自驾集结赛、鸭绿江马拉松、银杏节、开海节)

## 四、沿江品质提升(虎山—断桥核心段,约 20 公里黄金岸线)

### 4.1 空间结构梳理
- "一带四节点":虎山长城(起点仪式区)—国门湾(营地集散区)—老城滨江(生活休闲区)—断桥(核心体验区)
### 4.2 断桥片区升级
- 桥体光影夜游、江上实景演艺、纪念馆—断桥—安东老街动线一体化
### 4.3 慢行系统与服务界面
- 滨江骑行道/步道贯通、观景平台、驿站(补给 + 卫生间 + 充电)、标识系统统一到"起点"视觉体系
### 4.4 游船产品升级
- 分层产品:跨境视野观光航班、日落航班、餐饮/演艺主题航班、冬季破冰航线可行性
### 4.5 夜经济与滨江商业
- 安东老街扩容提质、江畔市集、夜航 + 夜市 + 夜演"三夜"联动
### 4.6 与城市更新结合
- 滨江老旧街区、工业遗存活化为文旅载体(详见第八章)

## 五、景区联动与票务组合

### 5.1 全域空间组织:"一江两线三圈"
- 一江:鸭绿江城市段主轴;两线:G331 边境线(虎山—河口—绿江)、G228 滨海线(东港—大鹿岛—獐岛);三圈:城市核心圈、宽甸山水圈、东港海岛圈
### 5.2 交通组织
- 旅游环线巴士、高铁 + 落地自驾(租车/房车)、景区接驳专线、营地网络布点
### 5.3 票务组合(借鉴万岁山"低价高频"逻辑)
- 城市通票(City Pass):N 日内多景区通行 + 游船/温泉折扣
- "起点护照"联票:集章兑换权益,绑定复游
- 单景区"一票三日无限次"试点、淡季极限定价、本地人/旅居者年卡
- 票务让利、二消(餐饮/住宿/文创)挣钱的收入结构再设计

## 六、旅游产品组合开发

### 6.1 自驾/公路旅行产品(第一优先级)
- "G331 首发站产品包":发车仪式 + 车辆检查补给 + 首晚住宿 + 沿线攻略;房车营地连锁化;摩旅/骑行友好城市配套
### 6.2 红色研学与国防教育产品
- 面向学校/机关/企业的标准化研学课程,纪念馆 + 断桥 + 河口的沉浸式课程设计(叙事庄重,慎用娱乐化)
### 6.3 边境体验产品
- 游船跨境视野、国门与界碑打卡、朝鲜族民俗村、边贸市场购物
### 6.4 康养旅居产品(对接银发经济)
- "温泉 + 海岛 + 江景"旅居套餐,按月计价的候鸟公寓,医养配套
### 6.5 美食与物产产品
- 黄蚬子/开海节单品引爆策划、草莓季(采摘 + 甜品节)、伴手礼体系(草莓、板栗、海产深加工)
### 6.6 沉浸式内容产品(借鉴河南,量力分期)
- 近期:小体量常态化演艺 + NPC 场景(安东老街、游船);中远期:鸭绿江夜游演艺、抗美援朝主题沉浸剧场的可行性论证
### 6.7 四季产品日历
- 春(河口桃花)、夏(避暑 + 海岛 + 自驾旺季)、秋(银杏 + 枫叶双景)、冬(温泉 + 冰凌 + 极限性价比旅居),消除断档

## 七、客群导入策略

### 7.1 客群分层与优先级
- 基本盘:辽吉黑都市圈短途周末客群
- 增量主力:京津冀高铁客群、全国自驾/摩旅/骑行圈层
- 战略客群:银发旅居候鸟(南客北上避暑 + 本地低成本越冬争议性评估)、亲子研学
- 远期:入境边境游(政策窗口跟踪)
### 7.2 渠道打法
- 自驾俱乐部/车友会 B 端合作、OTA 专题、老年大学与康养机构直连、研学机构课程共建、内容平台(抖音/小红书)达人共创
### 7.3 流量→留量→复游的转化机制
- 延长停留(夜产品 + 通票)、提高客单(二消场景)、制造复游理由(集章、季节限定、旅居身份权益)

## 八、更高维度:旅游驱动的城市发展

### 8.1 银发经济
- 旅居养老基地布局、医养结合能力建设、存量住宅改造为候鸟公寓、"旅居者市民待遇"包(公交、图书馆、社区医疗)
### 8.2 人口回流与就业
- 文旅创业扶持(民宿、营地、餐饮、内容创作者)、青年返乡计划、"新丹东人"引进政策与旅游产业岗位挂钩
### 8.3 城市更新
- 滨江带更新、老旧街区文旅化改造(安东老城)、闲置厂房/楼宇活化为文旅新空间,避免大拆大建、强调"微更新 + 运营前置"
### 8.4 产业联动
- 农文旅(草莓、板栗、海产)、边贸 + 旅游购物、交通枢纽经济(高铁 + 双国道)

## 九、实施路径与保障机制

### 9.1 分阶段行动
- 近期速赢:仪式感系统、票务通票、沿江驿站与标识、事件营销日历上线
- 中期系统:沿江品质工程、营地网络、旅居产品、演艺内容
- 远期深化:沉浸式旗舰项目、入境游、城市更新片区级项目
### 9.2 运营主体与机制
- 政府平台公司 + 专业运营团队(学河南引入市场化团队)+ 民营业态生态,明确"管委会管资源、公司管运营"
### 9.3 服务品质与口碑管理
- "不让游客受委屈"式服务承诺、投诉先行赔付、数据公示,口碑即最大的营销预算
### 9.4 风险与边界
- 边境与涉朝政策敏感性、红色叙事的庄重底线、季节性波动的现金流管理、避免重资产冒进
