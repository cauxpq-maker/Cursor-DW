# 旅顺口区海产品养殖加工产业专题分析报告（完整版）

本目录是该专题的全部成果，对应任务中的三份材料：完整版纲要、海产品养殖加工产业专题分析报告、“两菜”（海带、裙带菜）产业发展报告。

## 交付文件

| 文件 | 说明 |
| --- | --- |
| `旅顺口区海产品养殖加工产业专题分析报告（完整版）.docx` | 可编辑 Word 全文（标题可导航、表格可改、8 张图已嵌入） |
| `旅顺口区海产品养殖加工产业专题分析报告（完整版）.pdf` | 主报告 PDF（含两菜专项与数据口径附件） |
| `annex/旅顺口区两菜产业发展报告（独立报送稿）.pdf` | 从主报告拆出的两菜专项 |
| `report.html` | 排版源文件 |
| `charts/` 与 `charts.py` | 8 张数据图 |
| `annex/旅顺口区海产品产业数据手册.xlsx` | 9 张底表：指标、两菜、种业、加工、企业、地标、政策、对标、工程 |
| `annex/完整版纲要.md` 与 `报告完整版纲要（已补全）.docx` | 已填满的结构纲要 |

## 重建

```bash
python3 charts.py
python3 build_annex.py
python3 build_pdf.py
python3 build_docx.py
```

依赖：matplotlib、openpyxl、weasyprint。中文字体使用文泉驿微米黑。

## 口径

生产调度使用海带 3.4 万亩、鲜品近 30 万吨；地理标志宣传中的 6 万亩、约 30 亿元须单独标注来源，不可与生产口径加总。详见 PDF 编制说明与 Excel「封面与口径」。
